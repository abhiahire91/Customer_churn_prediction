<h2 style="color:#1d4ed8;">📌 Overview</h2>

<div style="background:linear-gradient(135deg,#0f172a,#2563eb); padding:12px; border-radius:10px; color:white;">
This project focuses on predicting <b>customer churn in the banking sector</b> using machine learning. 
The model identifies customers likely to leave and helps businesses take proactive actions to improve retention.
</div>

<hr>

<h2 style="color:#1d4ed8;">🎯 Objective</h2>

<ul>
<li>Predict customer churn using classification models</li>
<li>Analyze key factors affecting churn</li>
<li>Support data-driven business decision making</li>
</ul>

<h2 style="color:#1d4ed8;">📊 Model Performance</h2>

<div style="background:#022c22; padding:12px; border-radius:10px; color:white;">
✔️ Accuracy: <b>83.90%</b><br>
✔️ ROC AUC Score: <b>0.8635</b>
</div>

<hr>

<h2 style="color:#1d4ed8;">📌 Classification Report</h2>

<div style="background:#111827; padding:12px; border-radius:10px; color:red;">
<b>Class 0 (No Churn):</b><br>
Precision: 0.91 | Recall: 0.89 | F1-score: 0.90<br><br>

<b>Class 1 (Churn):</b><br>
Precision: 0.59 | Recall: 0.66 | F1-score: 0.62
</div>

<p style="color:#ef4444;">
<b>Insight:</b> Strong performance for non-churn prediction, but improvement needed for churn detection.
</p>
